# Физика

Здесь вы можете найти сканы моих домашек. По поводу физики я всё уже сказал, учить придётся много, будет тяжело, но не надо отчаиваться. Для допуска к самому экзамену нужно сдать 4 ДЗ и 4 защиты к ним (то есть повторить доказательство небольшой теоремы на 5-7 минут). К одной домашке необходимо написать ещё практическую защиту. В целом ничего сложного, чем раньше сдаёте, тем меньше надо учить для сдачи теории. Удачи!
