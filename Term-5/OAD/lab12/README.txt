1) Поднимаем контейнеры Apache Kafka в докере, используем docker-compose.yml
2) Устанавливаем все файлы по методичке (возможно, где-то надо будет откатываться на более старые версии)
3) Прописываем spark-3.5.7-bin-hadoop3 в переменную окружения SPARK_HOME
4) Запускаем контейнеры в докере, проверяем, что в lab12 всё работает, Kafka UI подгружается (остальные контейнеры особо не нужны, разве что ClickHouse)
5) Запускаем 2_1 в консоли, проверяем, что появились топики в Kafka UI
6) Аналогично запускаем каждую следующую лабу (Spark запускаем этой командой $SPARK_HOME/bin/spark-submit --packages org.apache.spark:spark-sql-kafka-0-10_2.12:3.5.7 spark_*.py)
7) Проверяем каждый топик в Kafka UI
8) В 2_3 отличий от 2_2 нет, данные для обучения модели в архиве
9) В 2_4 после включения producer и spark включаем api, заходим в терминал и пишем команду "curl "http://127.0.0.1:5001/recommend?user_id=*", где вместо * пишем id пользователя СТРОГО в формате "user_XX"
10) В 2_5 всё аналогично 2_4, для получения данных из api используем "curl "http://127.0.0.1:5002/metrics?host=hostX" и дальше по аналогии
